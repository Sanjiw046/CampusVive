# 🎓 CampusVive  

CampusVive is a **college event management platform** that simplifies how students and organizers handle events.  
Instead of manually asking every class for participation, organizers can post events online, and students can register with just a click.  
It also allows students to discover and participate in **inter-college/university events** if permitted by organizers.  

---

## 🚀 Features  
- 📌 **Event Creation & Management** – Organizers can create, edit, and manage college events.  
- 🎟 **Easy Registration** – Students register for events online without manual intervention.  
- 🌍 **Cross-College Participation** – Students can join inter-college events if enabled.  
- 🔐 **Authentication** – Secure login & registration for both students and organizers.  
- 📱 **Responsive UI** – Works seamlessly on desktop and mobile devices.  
- 📊 **Dashboard** – Organizers can track participants and manage events efficiently.  

---

## 🛠 Tech Stack  
- **Frontend:** React.js, HTML, CSS, JavaScript  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **Authentication:** JWT  
- **Version Control:** Git & GitHub
